# Customer-Churn-Prediction
Built an end-to-end machine learning pipeline in Python to predict customer churn for a telecommunications company using the IBM Telco Customer Churn dataset (7,043 customers, 21 features). Implemented and compared four classification algorithms — K-Nearest Neighbors, Decision Tree, Support Vector Machine, and a neural network (MLP) — with hyperparameter tuning via 2-fold cross-validation for each model. Evaluated models on accuracy, precision, recall, F1-score, and ROC AUC, and presented findings through a data-driven PowerPoint report covering data preprocessing, model comparison, and business recommendations for customer retention.
